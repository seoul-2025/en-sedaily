
|------|------|------|------|
| 대표 헤드라인 | 32px | Bold (700) | 1.3 |
| 섹션 제목 | 18px | Bold (700) | 1.4 |

- **서브 헤드라인**: 추경호 구속영장 기각…특검 "수긍할 수 없어"
