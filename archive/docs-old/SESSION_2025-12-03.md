## 🎓 Key Learnings

### 1. Lambda 환경
- `logging.basicConfig()` 작동 안 함
- `logger.setLevel()` 사용 필요

### 2. DynamoDB GSI
- 타입 불일치 시 ValidationException
- List → String 변환 필수

### 3. BigKinds API
- 2단계 프로세스 (Search → Detail)
- `result == 0` 체크 필수
- Rate limiting 필요 (1초 딜레이)

### 4. Next.js Static Export
- Query parameter 라우팅 사용
- Client-side data loading
- useEffect로 API 호출

### 5. TypeScript Best Practices
- any 타입 지양
- 명확한 인터페이스 정의
- 타입 재사용
