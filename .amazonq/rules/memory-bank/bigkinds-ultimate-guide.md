## 1. 시스템 개요

### 1.1 BigKinds란?

BigKinds는 한국언론진흥재단에서 운영하는 뉴스 빅데이터 분석 시스템으로, 뉴스 검색·분석·트렌드 파악 등의 기능을 API로 제공한다.

### 1.2 핵심 기능

| 기능 | 설명 |
|------|------|
| 뉴스 검색/조회 | 키워드 기반 기사 검색 및 상세 조회 |
| 이슈 랭킹 | 주요 이슈 자동 클러스터링 |
| 연관어 분석 | 키워드 간 연관성 분석 (워드클라우드) |
| 키워드 트렌드 | 시간별 키워드 등장 빈도 추이 |
| 키워드 추출 | 텍스트에서 핵심 키워드 자동 추출 |

### 1.3 데이터 수집 주기

- 하루 2회 (08시, 17시) 자동 분석 → 구조화 → 시각화

### 1.4 개체명 유형 분류

| 코드 | 분류명 | 예시 |
|------|--------|------|
| PS | 인물 | 윤석열, 문재인 |
| OG | 기관 | 헌법재판소, 국방부 |
| LC | 장소 | 서울, 광화문 |
| KT | 일반 키워드 | 탄핵, 선거 |

### 1.5 TopicRank 알고리즘

BigKinds는 단순 빈도(TF-IDF)가 아닌 **TopicRank** 그래프 기반 알고리즘 사용

| 단계 | 설명 |
|------|------|
| 1단계 | 기사 내 명사구(NP) 단위 키워드 후보 추출 |
| 2단계 | 유사 키워드 간 유사도 분석 및 군집화 |
| 3단계 | 토픽 간 연결 생성 (공동 등장 위치 기반) |
| 4단계 | PageRank 기반 중요도 계산 |
| 5단계 | 각 토픽당 대표 키워드 1개 추출 및 정렬 |

### 1.6 시스템 정확도

| 기능 | 정확도 |
|------|--------|
| 개체명 추출 | 약 93.3% (BERT 기반) |
| 뉴스 클러스터링 | 약 82.4% (Cosine Similarity) |

## 3. 뉴스 검색 API

### 3.1 기본 정보

- **URL**: `https://tools.kinds.or.kr/search/news`
- **용도**: 키워드 기반 뉴스 기사 검색
- **최대 결과**: 10,000건 (일부 언론사 15,000건)

### 3.2 요청 파라미터

| 파라미터 | 필수 | 설명 | 예시 |
|----------|------|------|------|
| `query` | ✅ | 검색 키워드 (AND, OR, NOT 연산 지원) | `"인공지능 OR AI"` |
| `published_at.from` | ✅ | 시작 날짜 (포함) | `"2025-04-01"` |
| `published_at.until` | ✅ | 종료 날짜 (제외) | `"2025-04-15"` |
| `provider` | ❌ | 언론사 제한 | `["서울경제"]` |
| `category` | ❌ | 카테고리 필터 | `["IT_과학"]` |
| `category_incident` | ❌ | 사건/사고 분류 | `["범죄", "교통사고"]` |
| `byline` | ❌ | 기자 이름 | `"홍길동"` |
| `sort` | ❌ | 정렬 방식 | `{"date": "desc"}` |
| `hilight` | ❌ | 하이라이트 길이 | `200` (최대) |
| `return_from` | ❌ | 시작 인덱스 | `0` (최대 20,000) |
| `return_size` | ❌ | 결과 개수 | `10` (최대 10,000) |
| `fields` | ❌ | 출력 필드 선택 | `["title", "content"]` |

### 3.3 검색 연산자

| 구분 | 연산자 | 사용 예 |
|------|--------|---------|
| 부울린 검색 | AND, OR, NOT | `사과 AND 배 NOT 과일` |
| 구문 검색 | "" | `"아담과 이브"` |
| 연산자 우선순위 | () | `(사과 OR 배) AND 과일` |

### 3.4 검색 영역 지정

```json
// 제목에서만 검색
"query": {"title": "검색어"}

// 본문에서만 검색
"query": {"content": "검색어"}

// 기본값: 제목+본문
"query": "검색어"
```

### 3.5 정렬 옵션

| 필드 | 정렬값 | 설명 |
|------|--------|------|
| date | desc/asc | 날짜순 |
| title | asc | 제목순 (오름차순만) |
| _score | desc | 정확도순 (내림차순만) |
| byline | asc | 기고자순 |
| provider_code | desc/asc | 매체코드순 |

### 3.6 출력 필드 (fields)

| 필드명 | 설명 |
|--------|------|
| `news_id` | 뉴스 식별자 |
| `title` | 제목 |
| `content` | 본문 |
| `published_at` | 발행일 (ISO 8601) |
| `enveloped_at` | 수집 시간 |
| `dateline` | 출고 시간 |
| `provider` | 언론사명 |
| `category` | 통합 분류체계 |
| `category_incident` | 사건/사고 분류체계 |
| `byline` | 기자명 |
| `images` | 이미지 파일명 |
| `images_caption` | 이미지 설명 |
| `provider_news_id` | 언론사 고유 식별값 |
| `provider_link_page` | 원본 링크 |
| `tms_raw_stream` | 추출 키워드 (명사) |

### 3.7 요청 예시

```python
url = "https://tools.kinds.or.kr/search/news"

payload = {
    "access_key": API_KEY,
    "argument": {
        "query": "인공지능 OR AI",
        "published_at": {
            "from": "2025-04-01",
            "until": "2025-04-15"
        },
        "provider": ["서울경제"],
        "category": ["IT_과학"],
        "sort": {"date": "desc"},
        "return_from": 0,
        "return_size": 10,
        "fields": ["title", "published_at", "content", "provider", "byline"]
    }
}

response = requests.post(url, json=payload)
result = response.json()
```

### 3.8 응답 구조

```json
{
    "result": 0,
    "return_object": {
        "total_hits": 691,
        "documents": [
            {
                "news_id": "02100311.20250414223657001",
                "title": "기사 제목",
                "content": "기사 본문...",
                "published_at": "2025-04-14T00:00:00.000+0900",
                "provider": "서울경제",
                "byline": "홍길동 기자"
            }
        ]
    }
```

## 4. 뉴스 조회 API

### 4.1 기본 정보

- **URL**: `https://tools.kinds.or.kr/search/news`
- **용도**: `news_id`로 상세 기사 정보 조회

### 4.2 요청 파라미터

| 항목 | 필수 | 설명 |
|------|------|------|
| `news_ids` | ✅ | 뉴스 ID 리스트 |
| `fields` | ✅ | 받고 싶은 필드 |

### 4.3 요청 예시

```python
# 1단계: 검색으로 news_id 수집
search_result = requests.post(search_url, json=search_payload).json()
news_ids = [doc["news_id"] for doc in search_result["return_object"]["documents"]]

# 2단계: news_id로 상세 조회
view_payload = {
    "access_key": API_KEY,
    "argument": {
        "news_ids": news_ids,
        "fields": ["title", "content", "byline", "images"]
    }
}

response = requests.post(url, json=view_payload)
```


## 7. 키워드 트렌드 API

### 7.1 기본 정보

- **URL**: `https://tools.kinds.or.kr/time_line`
- **용도**: 키워드 등장 빈도의 시간별 변화 추이

### 7.2 요청 파라미터

| 항목 | 필수 | 설명 | 옵션 |
|------|------|------|------|
| `query` | ✅ | 분석 키워드 | - |
| `published_at` | ✅ | 기간 설정 | - |
| `interval` | ✅ | 집계 단위 | `day`, `month`, `year` |
| `normalize` | ❌ | 정규화 여부 | `true`/`false` |
| `provider` | ❌ | 언론사 제한 | - |
| `category` | ❌ | 카테고리 필터 | - |

### 7.3 normalize 옵션

- `true`: 수집 문서건수 대비 정규화
- `false`: 원본 건수 (기본값)

### 7.4 응답 구조

```json
{
    "return_object": {
        "time_line": [
            {"label": "20250401", "hits": 12},
            {"label": "20250402", "hits": 7}
        ]
    }
}
```

### 7.5 시각화 예시

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({"날짜": dates, "기사 수": counts})
```

## 10. 오늘의 키워드 API

### 10.1 기본 정보

- **URL**: `https://tools.kinds.or.kr/today_category_keyword`
- **용도**: 분야별 (정치/경제/사회 등) 주요 키워드 자동 추출
- **특징**: 오늘 날짜 자동 적용, 별도 파라미터 불필요

### 10.2 요청 형식

```python
payload = {
    "access_key": API_KEY,
    "argument": {}  # 빈 객체
}
```

### 10.3 응답 구조

**cate_ratio (분야별 비중)**

```json
{
    "category_name": "경제",
```

## 11. 특성 추출 API

### 11.1 기본 정보

- **URL**: `https://tools.kinds.or.kr/feature`
- **용도**: 기사 제목/부제/본문에서 핵심 키워드와 중요도 점수 추출

### 11.2 요청 파라미터

|------|------|------|
| `title` | ✅ | 기사 제목 |

| `content` | ✅ | 본문 텍스트 |

### 11.3 응답 구조

```json
{
    "return_object": {
        "result": {
            "title": "AI|0.12 채용|0.11 서울시|0.10",
            "sub_title": "면접|0.09 프로그램|0.08",
            "content": "청년|0.15 구직자|0.13"
        }
    }
}
```

### 11.4 파싱 방법

```python
for field in ["title", "sub_title", "content"]:
    text = result["return_object"]["result"].get(field, "")
    for item in text.strip().split(" "):
        if "|" in item:
            keyword, score = item.split("|")
            print(f"{keyword} ({score})")
```

## 14. AI 활용 전략

### 14.1 언론사 선택별 응답 특성

| 비교 항목 | 단일 언론사 | 전체 언론사 |
|----------|------------|------------|
| 문체 스타일 | 간결, 단문, 사실 중심 | 해설 중심, 복합적 문장 |
| 응답 일관성 | 프롬프트 충실도 높음 | 다양한 논조 혼합 |
| 정보 범위 | 사건 위주, 시점 명확 | 전후 맥락 포함, 해석 확장 |
| 관점 반영 | 정치/행정 중심 | 사회/시민/제도 중심 |

> **주의**: 시각화는 언론사 설정과 무관하게 동일 출력. 언론사 조건이 적용되는 부분은 **텍스트 요약 응답**과 **출처 기사 리스트**에 한정

### 14.2 프롬프트 구성 요소

| 항목 | 설명 | 예시 |
|------|------|------|
| 시점 | 시간 범위 명시 | 최근, 2025년 4월 |
| 목표 | 분석 대상 핵심 | 탄핵 배경, 정치적 파장 |
| 형식 | 응답 구조 요구 | 서론/본론/결론, 마크다운, 표 |
| 스타일 | 문체/설명 톤 | 보도 기사체, 뉴스앵커, 초등학생 설명체 |
| 지시어 | 명령어 | 정리해줘, 설명해줘, 비교해줘 |

### 14.3 프롬프트 유형별 효과

| 유형 | 단일 언론사 | 전체 언론사 |
|------|------------|------------|
| 기사체 요약 (서론/본론/결론) | ★★★★★ | ★★★☆☆ |
| 뉴스앵커 브리핑 | ★★★★★ | ★★★☆☆ |
| 스토리텔링/쉬운 설명 | ★★★★☆ | ★★★☆☆ |
| 키워드 분류/표 정리 | ★★★★★ | ★★☆☆☆ |
| 관점 비교 분석 | ★★★★★ | ★★★☆☆ |

### 14.4 용도별 최적 설정

**단일 언론사 권장**
- 실무 요약, 보고서용 응답
- 빠른 브리핑, 팩트 중심 정리
- 표/포인트형 구조화 요청
- 비교 리포트, 정책 분석

**전체 언론사 권장**
- 사건의 해석적·사회적 의미 분석
- 시민 교육형 콘텐츠
- 다양한 관점 반영 필요 시
- 배경 설명, 맥락 확장 필요 시

### 14.5 실험 프롬프트 예시

```
P1: 최근 윤석열 대통령의 탄핵 배경과 정치적 파장을 서론, 본론, 
    결론 형식으로 언론사 기자가 보도하듯 정리해줘

P2: 2025년 4월 기준 윤석열 대통령 탄핵 이슈에 대해 마크다운 
    형식으로 작성하고, 뉴스앵커 스타일로 요약 브리핑 해줘

P3: 윤석열 대통령 탄핵 사건이 한국 사회 전반에 미친 영향을 
    스토리텔링 형식으로 설명하고, 초등학생도 이해할 수 있도록 
    풀어서 말해줘

P4: 윤석열 대통령 탄핵과 관련된 핵심 인물, 기관, 정치 키워드를 
    포인트별로 정리해줘. 정리 형식은 표로 만들어줘

P5: 윤석열 탄핵 이슈를 정치적 관점과 사회적 관점에서 각각 
    요약하고, 두 관점의 차이를 비교해줘
```

## 16. 실무 활용 가이드

### 16.1 API 선택 가이드

**키워드 추출 관련 API 비교**

| API | 점수 | 시간 정보 | 주요 용도 |
|-----|------|-----------|-----------|
| 특성 추출 | ✅ | ❌ | 단일 기사 키워드+중요도 |
| 키워드 추출 | ❌ | ❌ | 단일 기사 키워드 목록 |
| TopN 키워드 | ❌ | ✅ | 기간별 인기 키워드 순위 |
| 연관어 분석 | ✅ | ✅ | 특정 키워드의 연관어 |
| 오늘의 키워드 | ❌ | ❌ | 분야별 오늘의 핵심 키워드 |

### 16.2 활용 시나리오별 추천

**뉴스 요약 자동화**
1. 뉴스 검색 API → 기사 수집
2. 특성 추출 API → 핵심 키워드 파악
3. LLM 프롬프트에 키워드 삽입

**트렌드 분석 대시보드**
1. 키워드 트렌드 API → 시간별 변화
2. TopN 키워드 API → 인기 순위
3. 연관어 분석 API → 워드클라우드

**이슈 모니터링**
1. 오늘의 이슈 API → 자동 클러스터링
2. 뉴스 조회 API → 상세 기사 확인
3. 인용문 검색 API → 주요 발언 추출

### 16.3 통합 파이프라인

```
[뉴스 검색 API] → 키워드 기반 기사 수집
       ↓
[뉴스 조회 API] → 본문 확보
       ↓
┌──────────────┬───────────────┐
│ 키워드 추출   │ 트렌드 분석    │
│ 특성 추출    │ 연관어 분석    │
└─────┬────────┴───────────────┘
       ↓
[통합 요약] → LLM 또는 MCP 활용
       ↓
[시각화/리포트] → 워드클라우드, 차트, 카드뉴스
```

### 16.4 쿼리 검색 팁

**OR vs AND 구조**

| 조건 | 사용 시점 |
|------|----------|
| `"A OR B OR C"` | 전체 주제 범위 파악, 뉴스 탐색 단계 |
| `"A AND B"` | 특정 키워드가 동시에 언급된 연관성 높은 기사만 추출 |
| `"A AND B AND C"` | 매우 밀접한 맥락의 기사만 필요할 때 |

**타깃별 추천 쿼리**

| 타깃 | 추천 키워드 | 쿼리 예시 |
|------|------------|----------|
| 출장 직장인 | 산업, 공급망, 수출 | `산업 AND 정책 AND 제조업` |
| 투자자 | AI, GPT, 반도체, 스타트업 | `AI AND 투자 AND 시장` |
| 공공기관 | 정책, 행정, 디지털정부 | `정책 AND 공공 AND 데이터` |

### 16.5 프롬프트 작성 체크리스트

- [ ] 시점(기간) 명확히 지정했는가?
- [ ] 원하는 형식(표, 마크다운, 서론/본론/결론 등) 명시했는가?
- [ ] 문체 스타일 요청했는가?
- [ ] 목표(분석 대상)가 구체적인가?

### 16.6 언론사 선택 체크리스트

- [ ] 간결한 팩트 요약 필요? → 단일 언론사
- [ ] 다양한 시각 반영 필요? → 전체 언론사
- [ ] 구조화된 정리 필요? → 단일 언론사
- [ ] 해석적 서사 필요? → 전체 언론사

### 16.7 에러 처리

```python
if response.status_code == 200:
    result = response.json()
    if result.get("result") == 0:
        # 정상 처리
        data = result["return_object"]
    else:
        print("API 내부 오류:", result.get("reason"))
else:
    print("통신 오류:", response.status_code)
```

### 16.8 주의사항

1. **인증키 필수**: 모든 API 호출에 유효한 access_key 필요
2. **날짜 형식**: YYYY-MM-DD 엄격히 준수 (한국 시간 기준)
3. **until 날짜 제외**: until에 지정한 날짜는 검색 범위에서 제외
4. **fields 배열 필수**: 빈 배열이라도 반드시 포함
5. **페이징 제한**: return_from 최대 20,000, return_size 최대 10,000
6. **특수문자 이스케이프**: JSON 내 쌍따옴표는 역슬래시로 이스케이프 (`\"`)
7. **빈 결과 체크**: 항상 빈 리스트 확인
8. **rate limit**: 과도한 호출 자제
